# O site é o texto publicado do Plano de Ensino; o PDF aprovado é o registro formal

O Plano de Ensino nasceu num Google Doc. Decidimos transcrevê-lo para Markdown versionado no repositório, e o site passa a ser **o texto que a turma lê**. O Google Doc é congelado e marcado como versão histórica.

A separação que sustenta a decisão: o documento aprovado pelo colegiado continua sendo o registro formal, disponível para download em PDF e imutável dentro de uma **Oferta**. O site não substitui esse registro — ele publica o mesmo conteúdo numa forma consultável.

O motivo é que a rubrica de avaliação é o conteúdo mais procurado do site. Em Markdown ela vira URL linkável, entra na busca, lê-se no celular e aceita correção por pull request. Em PDF embutido não faz nada disso.

## Consequences

Manter as duas formas em acordo passa a ser trabalho manual e deliberado. Se o texto publicado divergir do documento aprovado, o site está errado — não o contrário. Alterar regra de avaliação no meio de uma Oferta editando Markdown seria mudar a regra do jogo sem passar pelo colegiado; a facilidade de editar não autoriza a mudança.
